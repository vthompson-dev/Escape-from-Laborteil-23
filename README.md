# Escape-from-Laborteil-23
Escape from Laborteil 23 is a text-based adventure game built with JavaScript. Use the sample commands and the clues in the game to navigate a fantasy laboratory and find your way home.

The setting and story are based off a Dungeons & Dragons one-shot campaign I wrote, which is itself based on a larger ongoing homebrew campaign. Please forgive any clunky word choices in the German text. Enjoy!
